## 使用说明

- 每篇文章为独立笔记，含 YAML frontmatter（标题、公众号、日期、主题、标签、原文链接），Obsidian 中可用搜索、标签和反向链接加工。
- 原文入口为永久有效的搜狗微信标题检索链接：点击后在结果页点第一条即达微信原文；微信内也可用「搜一搜」输入标题直达。
- 标注“公开镜像直达”的 2 篇有站外镜像，可直接打开全文。
- 同一份材料被多号转载的，已去重仅保留最早版本（共去重 1 篇）。
